LAB NOTE 001

MODEL EVALUATION / PREDICTIVE MAINTENANCE

When accuracy hides missed failures

A model can achieve high accuracy while missing important positive cases. Looking at precision and recall alongside accuracy provides a more useful picture of model performance.

TEST ACCURACY 98.05%
PRECISION 83.72%
RECALL 52.94%

Recorded test results from the current model. Recall highlights an important limitation: some actual failure cases were missed.
